# agent-voice and voicecheck

The agent-voice skill describes the writing standard. `scripts/voicecheck` sends every sentence of a document to a decision model and reports the ones the model says break the standard. The script needs Python 3.9 or later and uses only the standard library.

Run `scripts/voicecheck draft.md` from this skill directory, pipe text to `scripts/voicecheck -`, or invoke `voicecheck` when the command is on PATH. Use `--json` for machine-readable output and `--selftest` to exercise the model against the fixtures.

The script reads Markdown paragraphs, skips fenced code, and splits each block into sentences. Each sentence reaches the model with bounded context from its heading, list introduction, previous paragraph, and current paragraph. voicecheck sends these excerpts to AI Gateway.

Every request includes a safety identifier, the token the gateway gives the provider to attribute a call to one end user. The default hashes the local account and hostname into `voicecheck-<hex>`; set `VOICECHECK_SAFETY_IDENTIFIER` to use one identity across machines.

The default model is `openai/gpt-6-luna-decisions`. It returns a probability that the sentence has a problem and, separately, which of five problems it has. The report prints findings most confident first, with the line number, the sentence, the problem family and a fix. The confidence shown is the model's probability, not a measured correctness rate. When the model gives a probability but reports no family, the finding prints as `unclassified` with a general fix. There is no separate reasoning-model pass.

Treat a model result as a prompt to inspect the sentence. The decision call can flag factual bounds or intentional design choices despite the allowances in its instructions. Without `AI_GATEWAY_API_KEY` the command exits 2 and asks for the key.

The command sends one request per 24 sentences and waits for each answer before sending the next. `--threshold` moves the cutoff, `--top N` prints fewer findings, `--all` prints every one, and `--quiet` suppresses the report. Exit codes are 0 for no findings in every sentence, 1 for findings, and 2 when the input cannot be read, the key is missing, a self-test lacks a key, or a request fails after some sentences have been scored. The report and `--json` output state how many sentences were scored. Lines refer to the start of the Markdown block holding the sentence. The command concatenates multiple input files and prints the first file's path.

The development corpus holds 809 single sentences from 12 public repositories, labeled against the current SKILL.md without model scores in view. Each row records its repository as the stratum and its document kind: README, design doc, SKILL.md, AGENTS.md, prompt, or other. A passive is clean when its actor is the reader or is named in the sentence, and a contrast is clean when it names a real alternative. The sample is random within each document kind, so its violation rate does not estimate how often agents break the standard. At the shipped threshold the decision call reports 96 of the 125 violations and flags 192 of the 684 clean sentences, so most findings on a clean document are false alarms. `evals/run.py` sweeps thresholds against that corpus and accepts `--corpus PATH` for another JSONL dataset. It downloads each row's pinned source file once, into `~/.cache/voicecheck/corpus-sources`, and scores the sentences with the context voicecheck builds from that file; `--stored-context` uses the context saved in each row.

Run `python3 -m unittest -v test_voicecheck` from `scripts/` for deterministic tests. Run `./voicecheck --selftest` with `AI_GATEWAY_API_KEY` to check model recall against `evals/fixtures.jsonl`. The self-test reports false alarms but its exit code checks recall of the labeled violations.
