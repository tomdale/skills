# Critique

Use when asked only to critique a design. Change nothing.

## Procedure

1. Run core step 1 on the design as it is: reader and task, content, ranking and states.
2. Run core step 4's render, squint and exercise checks against that ranking and those states.
3. Run eradicate-ui-slop's review procedure on the source and screenshots.

## Report

For each problem, give its evidence (a screenshot region or source line), what it costs the reader, and the fix you'd make. List matters of taste separately from defects.
