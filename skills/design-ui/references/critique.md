# Critique

Run when asked only to critique a design. Change nothing.

## Procedure

1. Run core step 1 against the design as it stands: reader and task, content, ranking and states.
2. Run core step 4's render, squint and exercise checks against that ranking and those states.
3. Run eradicate-ui-slop's review procedure on the source and screenshots.

## Report

For each problem, give its evidence (a screenshot region or source line), its consequence for the reader, and the fix you would make. List matters of taste separately from defects.
